本仓库收录经过整理的文字材料和有限的代码摘录；不含原始聊天正文、凭据、敏感日志、数据库转储或虚拟机文件。v41 安装候选源码的敏感信息审查还未完成，因此尚未收录完整源码包；不同版本的候选不应混同为最终发布。文中实验机路径用于定位历史证据，不代表本仓库包含这些文件。本次整理没有连接虚拟机重新验证原始证据。
