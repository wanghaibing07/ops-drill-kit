# v41 代码摘录

这四个文件从 v41 安装候选的 `source.tar.gz` 中选出：导入中断状态分类器及对应单元测试，商户与订单的结构和合成示例数据。它们经过单独检查，仅用于阅读，不构成完整项目或可部署版本；原安装包与原 Git 历史未在此发布。

分类器只根据调用方已经核对的实例身份、行数和摘要给出观察，不连接数据库、不自动重试或授权修改。调用方必须自行校验 MySQL 实例身份与预期数据摘要。

从本目录运行 `python -m unittest discover -s tests/unit -p test_baseline_db_journal.py` 可执行摘录的单元测试。通过结果只证明这些单元测试，不代表实机导入或整个项目验收。
