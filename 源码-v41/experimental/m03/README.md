An agent-run socket-only database probe observed error 1040 after 8 synthetic connections, then confirmed recovery and stopped the temporary instances. The original tested source, state and hashes are preserved in /var/backups/opsdrill/M03/db-probe-41cc94fa59f1c0b5/. This project copy only adjusts the relative path to the M04 candidate controller. A bounded pool is now integrated into the lab API: each worker has separate old-order and Stage 3 pools of at most four connections each. In a disposable API process using the same pool code, holding all four old-order leases made readiness return 503; releasing them restored readiness to 200, while the main service remained healthy. The live service was restarted; health, readiness, old-order and Stage 3 endpoints then returned 200. The pool wait limit is one second; it does not bound database connect or query duration. This does not establish total database connection limits across other clients. At the time of this earlier observation, the full M03 CLI fault contract remained incomplete; see the later M03 runbook for subsequent results.
